# Оформление репозитория

Проверка от 28 октября 2026 года.

README сокращён до обзора, сборки и основных сценариев запуска. Подробности разделены на руководства
по командной строке, веб-интерфейсу, архитектуре и разработке.
[Обзор индекса](../docs/INDEX_GUIDE.md) содержит восемь ключевых участков с фрагментами C++ и
ссылками на строки исходников.

В `.clang-format` зафиксированы настройки clang-format 18, добавлены `.editorconfig` и
`scripts/format_cpp.sh`. Собственные C++-файлы приведены к общему оформлению. Порядок директив
`#include`, содержимое строк в кавычках и текст комментариев сохраняются. Внешняя библиотека
`third_party/json.hpp` не форматировалась.

## Проверки

- `format_cpp.sh --check` с clang-format 18.1.3 прошёл.
- Release собран; [все четыре набора CTest прошли](tests-repository-style.txt).
- Проверены локальные ссылки документации, заголовки и диапазоны ссылок на строки кода.
- Часть исполняемого файла с машинными командами, секция `.text`, до и после оформления побайтово
  совпала. SHA-256 обоих вариантов:

```text
7bccb4f5e51104e0d9f2abc2ebfff9a1c7a623b9e96c424eb61184a75eb1be99
```

Это изменение оформления и документации. Новые измерения производительности или повторное построение
корпуса в рамках этой проверки не выполнялись.
