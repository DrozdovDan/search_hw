# Отчёты

Здесь хранятся результаты конкретных запусков и протоколы проверок. Числа относятся к указанным
корпусам, параметрам и оборудованию.

## Основные материалы

| Документ                         | Содержимое                                                                                             |
| -------------------------------- | ------------------------------------------------------------------------------------------------------ |
| [RESULTS.md](RESULTS.md)         | Построение индексов для полного MS MARCO и первых N документов, измерение запросов и сравнение advance |
| [WEB.md](WEB.md)                 | Проверка HTTP API, полного текста и веб-интерфейса                                                     |
| [WEB_CONTEXT.md](WEB_CONTEXT.md) | Контекстные фрагменты, подсветка и переходы по совпадениям                                             |

Проверка оформления исходников и ссылок документации вынесена в
[отдельный протокол](REPOSITORY_STYLE.md).

## Исходные результаты

| Шаблон или файл                                                          | Что содержит                                                  |
| ------------------------------------------------------------------------ | ------------------------------------------------------------- |
| `final-msmarco-*.build.json`                                             | Количество записей, время и память при построении по MS MARCO |
| `final-synthetic-*.build.json`                                           | Те же показатели для синтетического корпуса                   |
| `*.time.txt`                                                             | Вывод `/usr/bin/time -v`                                      |
| `*.stats.json`, `*.validate.txt`                                         | Статистика и структурная проверка готового индекса            |
| `*-binary.json`, `*-sequential.json`                                     | Запросные измерения для двух алгоритмов переходов             |
| [final-synthetic-intersections.json](final-synthetic-intersections.json) | Отдельное сравнение пересечений списков                       |
| [msmarco-full-equivalence.txt](msmarco-full-equivalence.txt)             | Побайтовое сравнение двух полных построений                   |
| [msmarco-1m-equivalence.txt](msmarco-1m-equivalence.txt)                 | Сравнение построений индекса для первых миллиона документов   |
| [msmarco-md5.txt](msmarco-md5.txt)                                       | Проверка исходного архива                                     |
| [search-restart.txt](search-restart.txt)                                 | Поиск после повторного открытия индекса                       |
| [offset-counter.strace.txt](offset-counter.strace.txt)                   | Проверка системных вызовов при записи и слиянии               |

`tests-*.txt` фиксируют результаты проверок на дату соответствующего изменения. Их состав может
различаться: веб-тесты добавлены позже исходного C++-набора. Скриншоты `web-*.png` относятся к
проверенному состоянию интерфейса.

Для повторения экспериментов см. [методику](RESULTS.md#повторение) и
[руководство по запуску](../docs/USAGE.md#измерения).
